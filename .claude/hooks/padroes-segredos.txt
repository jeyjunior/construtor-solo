# Padrões de segredo usados por bloquear-segredos.sh (edição do Claude) e pelo pre-commit do git
# em .claude/git-hooks/ (commit de qualquer pessoa). Expressão regular estendida do grep.
# Formato: PADRAO  ou  PADRAO|||EXCECAO
#   EXCECAO é uma expressão regular aplicada ao caminho do arquivo relativo ao Root (ex.: Projeto/src/A.cs);
#   quando casa, o padrão não vale para aquele arquivo.
# Linhas vazias e começadas por # são ignoradas. Origem: vault (portado do gitleaks).

# Atribuição de senha/token/chave com valor literal entre aspas (8+ caracteres)
([Aa][Pp][Ii][_-]?[Kk][Ee][Yy]|[Pp]ass(word|wd)|PASS(WORD|WD)|[Tt]oken|TOKEN|[Ss]ecret|SECRET)\s*=\s*["'][^"']{8,}["']|||(^Projeto_Documento/|\.md$|\.example$|\.sample$)

# Senha em connection string (Password=... ou Pwd=..., sem espaço antes do =)
([Pp]assword|PASSWORD|[Pp]wd|PWD)=[^;"'[:space:]{$]{4,}|||(^Projeto_Documento/|\.md$|\.example$|\.sample$)

# Chave privada (RSA, OPENSSH, DSA, EC, PGP, ENCRYPTED)
-----BEGIN [A-Z ]*PRIVATE KEY-----

# JWT aceitando algoritmo "none"
(algorithms|alg)\s*[:=]\s*\[?\s*["']none["']
